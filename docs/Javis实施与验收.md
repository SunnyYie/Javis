## 数据与迁移

职业表结构未改，不自动搬运旧记录。当前配置路径未发现正式职业库或记忆库，
因此历史迁移验收使用隔离复制的测试历史结构，不声称测试过用户真实历史数据库。
旧记忆缺少 `scope` 时仅归 `career`，
租房不读取职业记忆。跨域分享必须选定岗位、预览最小地点摘要、
宿主 `/share confirm` 后再次确认新版租房需求，不传薪资、履历或面试文本。

新增任务库使用 `PRAGMA user_version=1`。对已有 version 0 数据库执行升级前
通过 SQLite backup 生成 `*.v0.bak`，增表与版本更新在事务中完成。
复制历史结构的离线测试验证原记录 ID 不变、幂等、失败回滚；
`javis_core.storage.rollback(path)` 检测迁移后指纹，
若已有新写入则拒绝回滚，不恢复旧备份覆盖新增数据。

来源快照和任务结果默认启动时按 7 天保留期清理；精确目的地授权过期
移除坐标并使确认失效。`javis sessions delete ID` 可删除该会话在三个域的数据，
不删除共享知识库、用户原文件或每日配额台账；不清理外部备份。
文件权限不等于加密。没有后台清理或后台自动找房。
