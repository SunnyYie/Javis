# 画像收集
适用：没有简历、补充经历、澄清个人职责或量化成果。

1. 查看已有事实，先问目标和缺失信息，不猜岗位、城市或薪资。
2. 每次聚焦一段经历，询问时间、背景、个人行动、成果和可验证证据。
3. 用用户原话 quote 提出事实候选，不将招聘要求或模型建议写成个人事实。
4. 展示候选 ID，等待用户 `/facts confirm ID`；绝不自行确认。

产出：有来源的事实候选、缺口和下一条具体问题。联系方式仅由 `/contact` 本地保存。
