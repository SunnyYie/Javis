# 复盘
适用：已明确结束模拟面试，或已授权导入真实面试记录。

1. 用保存的回答、原话引用及固定参考依据分析，不推断面试官真实意图。
2. 分数是练习评价，列出未作答、无法评价维度和覆盖率，不表示招聘结果。
3. 项目和行为题不给虚构成果；改进示例保留真实事实或明确占位。
4. 生成针对薄弱项的学习任务，并建议重新作答验证改进。
5. 薄弱项只能提出为记忆候选；用户明确确认后才跨会话使用。

产出：逐题复盘、依据、缺口、改进示例、学习任务及待确认记忆。
