### 失败与限制

1. 初次本地资料不足时返回 `sufficient=false`，按原断言失败；后续通过真实联网
   补充资料，不把来源不足改为成功。
2. 行为面试模型曾产生伪引文，校验阻止推进。最终使用回答片段编号，由程序还原原话，
   非法编号仍阻断；不可核验的行为真实性维度不计分，评价最多重试一次。
3. 终端测试曾暴露前置场景耦合、JSON 显示隐藏 ID、交互输出与 JSON 封装混淆，
   以及把“无错误：”误判为错误的问题。修复后在新应用/记忆目录重跑完整 PTY。
4. **初轮正式库版本不变断言未通过**：运行期间题库版本从 612 变为 621，之后只读观察
   到 629，来源更新时间也变化。未回退外部变化，原因未证实，不能据此宣称正式库
   全程未变化，也不能仅凭版本变化认定是本 Agent 写入。需要停止其他写入后重测。
   当时后续核心验收排除了该断言，因此不能将整个 live 文件报告为全部通过。
   清理后的专项复测已通过，范围和证据见本文首节；不抹除初轮失败，也不确定其原因。
